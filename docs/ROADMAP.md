## 🚀 CrazyGames パブリッシング・申請プロセスの流れ (Publishing Flow)

CrazyGames の正式公開は、**「まずゲーム単体のクオリティを高めて一次審査（Basic Launch）をクリアし、承認後に SDK（広告・収益化）を組み込む」** という正しいステップで進行します！

```
【Step 1: ゲームクオリティ向上 & Basic Launch 申請】 
      ↓ (審査通過・一次承認！)
【Step 2: CrazyGames SDK 組み込み (広告・広告ミュート・イベント連携)】 
      ↓ 
【Step 3: フル公開 (Monetized Full Launch)】
```

---

## 📋 CrazyGames 必須チェックリスト (CrazyGames Requirements)

### 🔴 【Step 1】 Basic Launch 審査通過に必要な項目 (広告なし・ゲーム単体)
- [ ] **高クオリティな視覚演出・ゲームプレイ体験** (Juiciness, コンボ感, リズム同期)
- [ ] **英語対応 (Localization)**
  - [ ] 英語 (English) ↔ 日本語 (Japanese) の言語切り替え対応
- [ ] **マルチデバイス / レスポンシブ最適化**
  - [ ] PC（キーボード/マウス）および モバイル（タッチ）の完全スムーズ対応
  - [ ] 画面リサイズ・全画面表示（Full Screen）時のアスペクト比追従

### 🔵 【Step 2】 Basic Launch 承認後に導入する項目 (CrazyGames SDK)
- [ ] **CrazyGames SDK (v2/v3) の導入**
  - [ ] ゲーム開始 / 終了 / ポーズ時の `gameplayStart()`, `gameplayStop()` イベント呼び出し
  - [ ] ステージクリア時・リトライ時のミッドロール広告 (`ad.requestAd`) 実装
  - [ ] コンティニュー（復活）用のリワード動画広告連携
  - [ ] 広告再生中の BGM / SE 自動ミュート連動

## 📅 フェーズ別クオリティアップ計画 (Development Roadmap)

### 🎨 Phase 1: Juiciness & 視覚演出の極致 (爽快感・手応え)
タップした瞬間の「打撃感」と「気持ちよさ」を100倍にする演出強化。

- [ ] **PERFECT / GREAT / MISS 判定文字エフェクト**
  - [ ] 判定リング上またはタップ位置に、ネオン発光するポップアップテキストがシャキーンと跳ねて消える演出
- [ ] **スクリーンシェイク (画面振動)**
  - [ ] PERFECTタップ時、ボス撃破時、ミスダメージ時に画面がガツンと微振動する臨場感
- [ ] **コンボヒートアップ背景演出**
  - [ ] 50コンボ、100コンボに達すると背景のグリッドラインが激しく脈動しカラーがカラフルに変化

---

### 🎵 Phase 2: 音ゲーとしての精度向上 (BPM・時間同期)
テンポに乗って爽快に打ち込める本格リズムゲーム体験。

- [ ] **Web Audio API による BPM 完全同期**
  - [ ] `setInterval` から、`AudioContext.currentTime` による音楽の経過時間に100%一致したノーツスポーン処理へのアップグレード
- [ ] **ノーツ打撃音（SE）のバリエーション＆チューニング**
  - [ ] PERFECT / GREAT の音分けおよび、連続タップ時のメロディ感演出

---

### 🏆 Phase 3: メタゲーム & やり込みシステム (Progression)
プレイヤーが毎日遊びたくなる進行感とコレクション要素。

- [ ] **3つ星評価システム (3-Star Rating)**
  - [ ] 各ステージのスコア・精度（PERFECT率）に応じて ⭐⭐⭐ 評価を表示
- [ ] **ステージアンロックシステム**
  - [ ] EASYの一定ステージをクリアすると NORMAL モードが解放される段階的進行感
- [ ] **プレイヤーリング・スキンの解禁**
  - [ ] ハイスコアやクリア報酬で、リングのデザイン（ネオン・ファイア・サイバー）やタップエフェクトを着せ替え可能に

---

### 📦 Phase 4: SDK組み込み & 審査申請 (CrazyGames Release)
CrazyGames パブリッシングと最終ブラッシュアップ。

- [ ] CrazyGames SDK 統合・ローカルテスト（SDK Test Mode）
- [ ] 英語テキストの最終チェック
- [ ] CrazyGames Developer Portal からの審査申請（Submission）
