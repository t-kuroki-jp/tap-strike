# 『Tap Strike』 全エネミー & ノーツ完全カタログ (Enemies Catalog)

---

## 1. 概要 (Overview)

本ドキュメントは『Tap Strike』に登場する全エネミー・ノーツの仕様、形状、カラー、移動 Behavior、ID、および対応クラス名を完全一元管理するカタログ仕様書です。

全エネミーは `js/enemies/` 配下にカテゴリ別でモジュール化されており、共通の基底クラス `Enemy` (`js/enemies/enemy.js`) を継承しています。

### 🧩 動的レジストリ ＆ シールドカプセル化構造
- **動的プラグイン登録 (`EnemyFactory.register`)**:
  新しいエネミーノーツの JS ファイルを追加し、`EnemyFactory.register(id, EnemyClass)` を呼ぶだけで、ゲーム本編のスポーン・図鑑表示（`getAllMetadata`）へ自動連動します。
- **カプセル化シールド描画 (`drawShieldLayer`)**:
  全エネミーノーツの `draw(ctx)` 末尾で `this.drawShieldLayer(ctx)` が自動呼び出しされます。ステージデータの JSON で `hp: 2`（耐久バリア）が指定された場合、全ノーツ共通で青色の発光シールドリングが自動描画されます。
- **図鑑 (Character Book) コンパクトデザイン**:
  冗長な解説文を排し、**「プレビュー描画 ✕ ノーツ名 ✕ 一言ネオンバッジ (tag)」** の 3 要素に特化したコンパクト＆レスポンシブデザインへ洗練されています。
