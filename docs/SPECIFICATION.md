## 1. ゲーム概要 (Game Architecture)

『Tap Strike』は、画面外から中心の「判定リング」に向かってアプローチしてくるノーツ（エネミー）を、タイミング良くタップして撃破する円形全方位リズム・タップゲームです。

### モード体系 (Difficulty Modes)
- 🟢 **EASY モード**: 全 10 種類の移動 Behavior（行動ロジック）を純粋な幾何学ノーツで 1 ステージずつ安全に学べるチュートリアルコース。
- 🔵 **NORMAL モード**: 高速ノーツ、シールド（HP2）、ボス（HP5連打）、ドントタップ（禁止ノーツ）などのゲームルールギミックに挑戦する標準コース。
- 🔴 **HARD モード**: 幾何学ノーツ ✕ 複雑な複合 Behavior の高難易度オーバードライブコース。
- 🤪 **FUNNY モード**: ひよこ、ネコファミリー、回転寿司、柴犬、満開夜桜、花火などの賑やかなキャラクターやテーマ別のお楽しみお祭りコース。

> 💡 **エネミー詳細カタログ**: 全エネミーの各種パラメータ、色、クラス構造は分離された [全エネミー & ノーツ完全カタログ (docs/ENEMIES.md)](file:///c:/Users/g35cz/dev/tap-strike/docs/ENEMIES.md) を参照してください。

## 3. スマート・スポーン制御 (Smart Spawn Protection)

ノーツ同士が判定リング上で物理的に重なって出現し、連打が物理的に間に合わず理不尽死してしまうアンフェアなミスを防ぐセーフティシステムです。

- **処理アルゴリズム (`js/game.js` - `spawnSmartEnemy`)**:
  1. 新規出現エネミーの判定リング到達予想時刻 (`candETA = 距離 ÷ スピード`) を算出。
  2. 現在画面上に存在する既存全ノーツの到達予想時刻 (`exETA`) と比較。
  3. 到達時間差が連打不可能な危険ゾーン (`10フレーム / 約160ms` 未満) であれば、スピードを微調整して出撃タイミングを自動シフト！
- **効果**: 判定リング到達時刻が物理的に重ならなくなるため、プレイヤーの「連打（タタタン！）」で 100% 確実に実力通り撃破可能になります！

## 5. エネミー開発アーキテクチャ ＆ 実装ルール (Enemy Architecture Guidelines)

新しいエネミーを追加・作成する際は、ゲームプレイの手応えの統一性と品質を保つため、以下の **3階層開発ルール** に従って実装します。

### 📌 階層1: 標準ノーツ (基本パターン)
- **原則**: 基底クラス `Enemy` (`js/enemies/enemy.js`) を継承し、**`draw(ctx)`（見た目の描画）のみを実装**する。
- **効果**: ヒット判定・PERFECT判定・コンボ/スコア計算・黄金エフェクト・ショックウェーブ生成は親クラスが一括処理するため、判定や演出の漏れが100%発生しません。

```javascript
class StandardEnemy extends Enemy {
    constructor(canvas, gameSpeed, stage) {
        super(canvas, gameSpeed, stage, { id: 'MY_NOTE', name: 'マイノーツ', color: '#ff00ff', size: 14 });
    }
    draw(ctx) {
        // 描画処理のみを記述
    }
}
```

### 📌 階層2: 装飾・サウンド拡張ノーツ (アドオンパターン)
- **原則**: 独自の効果音（「ニャー！」「ポコッ♪」）や追加パーティクル（「お皿の白」「肉球」）を持つノーツは `onHit` を定義するが、**冒頭で必ず `super.onHit(game, touchX, touchY, isPerfect)` を呼び出す**。
- **効果**: 共通の手応え・PERFECT演出を100%保証した上で、ノーツ独自の演出を安全に追加・ブレンドできます。

```javascript
onHit(game, touchX, touchY, isPerfect) {
    super.onHit(game, touchX, touchY, isPerfect); // ★必須共通呼び出し
    this.playCustomSound();                         // ★固有追加処理
    return true;
}
```

### 📌 階層3: 特殊ギミック・FUNNYモード (例外パターン)
- **原則**: 爆弾（叩くとダメージ）や変身ボスなどの特殊ギミックノーツに限り、例外として `onHit` を完全独自定義することが許可されます。
