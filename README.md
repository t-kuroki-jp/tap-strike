# Tap Strike (秒殺！1ボタンアクション)

ワンボタンで遊べる音ゲー風味のタイミングアクションゲームプロトタイプ。

## 概要

画面外から中心へ向かって迫り来る敵を、自機の周囲に展開される判定リングに重なるタイミングでタップ/クリックして撃破するハイスピードアクションゲームです。

## 特徴

- **シンプル操作**: タイミングに合わせて画面をタップまたはクリックするだけ
- **Web Audio API 活用**: 音声・BGM・効果音をリアルタイム合成
- **3段階の難易度**: EASY / NORMAL / HARD
- **ネオンサイバー演出**: パーティクル、ショックウェーブ、動的背景エフェクト

## プレイ方法

1. `index.html` をブラウザで開きます。
2. タイトル画面で難易度を選択してスタートします。
3. 迫る敵が中心の判定リングに到達したタイミングで画面をタップ/クリック！
